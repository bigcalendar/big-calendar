# Failed approaches

Approaches that were tried and failed, so nobody retries them without a new reason. Decisions never go here (they go in `docs/decisions.md`).

Add each entry as:

```md
### YYYY-MM-DD — <short title>

- **Tried:** what was attempted.
- **Failed because:** what went wrong (error, measurement, spec conflict).
- **Instead:** what worked, or "open".
```
