# Big Calendar

Big Calendar is a toolkit for building calendar and scheduling apps in the browser. It's the successor to [react-big-calendar](https://github.com/jquense/react-big-calendar).

It's **headless first**. A framework-free core does the work: dates and time zones, layout, and every keyboard, pointer and screen-reader interaction. A thin React binding connects it to React, and an optional set of prebuilt components gives you a calendar you can drop in and style.

## Status

**Not ready to use.** Nothing is published to npm yet, and the API may still change before 1.0.

The design is finished and the build has started. The first slice of work (S0) sets up the workspace, tooling and CI. The month view comes next.

An earlier attempt is archived as the `archive/attempt-1` branch. Nothing from it is reused.
