# Big Calendar

**Before you start:** nothing. This page needs no setup.

Big Calendar is a toolkit for building calendar and scheduling apps in the browser. It's the successor to [react-big-calendar](https://github.com/jquense/react-big-calendar).

**It isn't ready to use yet.** Nothing is published to npm, and the API may change before 1.0. These docs grow with each piece of work, so every page here describes something that exists.

## How these docs are organized

The docs have four kinds of page. Each kind does one job.

- **Tutorial:** one app, built step by step. It starts with the month view.
- **How-to guides:** the steps for one task, such as loading events from a server.
- **Reference:** every type and function, generated from the source code.
- **Explanation:** the ideas behind the design, such as how dates and time zones work.
