# Reference

These pages list every exported type and function, with the documentation written next to the code. They're generated from the source each time the site is built, so they always match the code.

Each package has its own section: `core` (the data, options and state), `interactions` (the machines and prop-getters), `react` (the hooks) and `react-ui` (the prebuilt components).
